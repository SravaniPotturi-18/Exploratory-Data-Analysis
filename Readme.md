# Task 5: Exploratory Data Analysis (EDA) – Titanic Dataset

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Titanic passenger dataset using Python. The objective is to identify patterns, trends, relationships, missing values, and potential outliers through statistical analysis and data visualization.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Statsmodels

## Analysis Performed
- Dataset overview using `info()` and `describe()`
- Missing-value and duplicate checks
- Categorical analysis using `value_counts()`
- Survival rate calculations
- Histograms and boxplots
- Bar charts and scatterplots
- Correlation heatmap and pairplot
- Multicollinearity assessment using VIF

## Key Findings
- Survival outcomes differed by gender and passenger class.
- Passenger age and fare distributions showed variation.
- The fare distribution contained potential outliers.
- Some columns contained missing values that required consideration during analysis.
- Correlation and VIF were used to investigate relationships among numerical variables and potential multicollinearity.

## Conclusion
EDA helped identify important patterns, data-quality issues, and relationships in the Titanic dataset. The project demonstrates how statistical summaries and visualizations support data-driven analysis.
